# A + B Problem

## Problem Description

Write a program that reads two integers, `A` and `B`, and outputs their sum.

### Input Format
- The input consists of a single line containing two integers, `A` and `B`, separated by a space.

### Output Format
- Output a single integer, which is the sum of `A` and `B`.

- `-10^9 <= A, B <= 10^9`

---

## Examples

### Example 1
**Input:**
```
1 2
```

**Output:**
```
3
```

### Example 2
**Input:**
```
-5 10
```

**Output:**
```
5
```

---

## Notes
- Ensure that your program handles large integers within the given constraints.
- The input will always be valid, so no need to handle invalid input cases.
